# Encuentra UNISON

## Iniciar proyecto

1. Instalar dependencias

   ```bash
   npm install
   ```

2. Ejecutar la app

   ```bash
   npx expo start
   ```

3. Abrir [http://localhost:8081](http://localhost:8081) en el navegador.
